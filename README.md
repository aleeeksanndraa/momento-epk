# Momento — Partnership EPK

Single-page electronic press kit for Momento (music, nightlife and creative collaborations, London & Madrid).

- `index.html` — the page
- `css/style.css` — styles
- `js/main.js` — motion (GSAP + ScrollTrigger + Lenis, loaded from CDN)
- `assets/` — images and short compressed video clips

Static site, served with GitHub Pages from the `main` branch root.
To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
